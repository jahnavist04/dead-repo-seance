One-time setup (30 seconds)

This site talks to Ollama running on your own computer, so there's no server, no API key and no data leaves your machine except the public GitHub API.

1. Install Ollama and run ollama pull gemma3:4b

2. Allow this site to talk to it. In PowerShell:

setx OLLAMA_ORIGINS "https://jahnavist04.github.io"

3. Quit Ollama from the tray, reopen it, then refresh this page. If Chrome asks to allow local network access, click Allow.
